# Конфигурация «Управление фитнес-центром»

## Описание проекта
Система оперативного учёта, CRM, автоматизации продаж абонементов и взаимодействия с клиентами через мобильное приложение для фитнес-клуба.

Проект выполнен в качестве итоговой дипломной работы на курсе «1С-разработчик» в Яндекс Практикуме. Основные задачи — проектирование архитектуры с нуля, создание удобного инструментария массовой загрузки данных, автоматизация расчёта зарплаты тренеров, а также разработка клиентского мобильного приложения для онлайн-записи.

### Стек технологий и механизмов
* **Платформа:** 1С:Предприятие 8.3 (Управляемое приложение, Мобильная платформа 1С)
* **Язык разработки:** Встроенный язык 1С
* **Бизнес-логика:** Справочники, Документы, Перечисления, Регистры сведений и накопления
* **Автоматизация:** Обработка и чтение табличных документов (`XLS`, `XLSX`, `MXL`), автоматическое создание элементов справочников при проведении документов
* **Интеграции и мобильная разработка:** Мобильное приложение 1С, сервисы авторизации, регистрации клиентов и онлайн-записи
* **Аналитика и UI:** Система компоновки данных (СКД), Пользовательское стилистическое оформление форм, Подсистемы

## Выводы по результатам проекта
1. **Ускорение ввода данных:** Внедрение обработки импорта прайс-листа из табличных документов позволило сократить время обновления цен в регистре «ЦеныНоменклатуры» с десятков минут до нескольких секунд.
2. **Повышение конверсии и удобства клиентов:** Интеграция мобильного приложения с основной базой обеспечила автоматическое создание контрагентов и проведение предварительных записей без участия менеджера.
3. **Автоматизация рутинного учёта:** Связка документов продажи с автоматическим формированием именных абонементов исключила ошибки ручного ввода и повысила прозрачность учёта действующих услуг.

## Системные требования и инструкция по развёртыванию

### Системные требования
* **Платформа 1С:Предприятие:** версия 8.3.20 или выше (с поддержкой Мобильной платформы).
* **Операционная система:** Windows 10/11, Linux или macOS.

### Инструкция по развёртыванию
1. Скачайте файл выгрузки информационной базы (`1Cv8.dt`) из репозитория.
2. Запустите «1С:Предприятие» и нажмите кнопку **«Добавить...»**.
3. Выберите **«Создание новой информационной базы»** -> **«Создание информационной базы без конфигурации...»**.
4. Укажите название базы (например, *«Фитнес-центр»*) и каталог на диске.
5. Запустите созданную базу в режиме **«Конфигуратор»**.
6. В меню выберите: **Администрирование** -> **Загрузить информационную базу...**
7. Укажите путь к скачанному файлу `1Cv8.dt` и подтвердите загрузку.
8. Перезапустите базу и войдите в режиме **«1С:Предприятие»**.
